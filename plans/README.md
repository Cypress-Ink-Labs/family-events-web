## Findings considered and rejected

- **`use-enriched-events.ts` date-cache "bug" (3 subagent reports: `getMonth()` 0-indexing,
  day-boundary staleness, race condition)**: false positives. The `${year}-${month}-${date}`
  key (`startOfTodayIso`, line 38) is only ever compared against itself; `getDate()` already
  invalidates the cache on a day change; JS is single-threaded so no race. `getMonth()`
  returning 0–11 is cosmetic, not a collision. Cache is correct as written.
- **JSON-LD `dangerouslySetInnerHTML` XSS (`event-json-ld.tsx`)**: `JSON.stringify` output
  inside `<script type="application/ld+json">` is the standard safe pattern; not exploitable.
- **IDOR / RLS / mass-assignment (admin RPCs, city update)**: the authorization boundary is
  Supabase Row-Level Security in the backend repo. Client-side checks are UX gating by design.
- **"Document the TS6 / Node25 / Tailwind4 / Vite8 stack" (deps)**: generic; build + typecheck
  pass; no concrete action.
